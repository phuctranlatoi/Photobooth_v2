## Overview
The matrix lists every behavioural feature that exists in V1, the exact source file(s) where it is implemented, and a concrete plan for V2. It distinguishes three evidence levels:
- **Observed** – implementation was read directly (full source).
- **Observed import** – only the class import appears in V1 sources; the implementation file has not been opened, therefore the behaviour is **unverified**.
- **Missing** – we have not opened the implementation and lack test evidence.
