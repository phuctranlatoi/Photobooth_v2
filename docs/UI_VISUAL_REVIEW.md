### 16:10 and V1 palette / typography

- Both target pixel sizes are 16:10. At a **CSS viewport** of 1920×1200 the `.v1-shell` horizontal padding is 76.8px per side and inner width approximately 1766px; at 1280×800 it is 51.2px and approximately 1178px. Header minimum 90px, shell top/bottom padding 48px and gap(s) 20px, and action footer minimum control 56px leave less room at the compact size; `.v1-split` independently scrolls. `.v1-photo-grid` is fixed at six columns above 900px, so at 1280 wide its left 1.4/2 grid region is roughly 800px and individual photos can approach ~115px width before gaps. This is a **calculation, not DOM measurement**. The ≤900px breakpoint does not trigger at a 1280px CSS viewport. If Windows scaling reduces effective CSS width (e.g. 1280 physical pixels / 150% ≈853 CSS pixels), the three-column rule triggers, but other fixed/flex content, operator six-tab nav and 304px QR placeholder need direct verification. Do not equate physical pixels with CSS px or presume a WebView device-scale mapping.
- V1 Compose `Theme.kt` confirms `#FBF9F6` background, `#242424` ink, `#C27357` accent, `#A65D43` dark accent, `#F4EFEA` alternate, `#E8E2DC` border, and sans-serif typography. New `kiosk-v1.css` uses those same core values and `Segoe UI`/system sans. Requested `#EAE5DF` is **not** V1's literal border (`#E8E2DC`): treat as approximate neutral, not exact fidelity. New shell has **two decorative radial gradients** absent from the inspected V1 theme; remove if strict flat V1 parity is the goal. Admin uses Arial, related but not the same font stack; global `styles.css` still specifies Georgia for unscoped headings, so verify actual cascade in mounted screens rather than assuming all admin headings are sans.
- Calculated WCAG contrast: white text on `#C27357` primary ≈**3.57:1** (fails 4.5:1 for regular 18px/700 text, qualifies for large-text threshold only); white on `#A65D43` ≈**4.92:1**; muted `#8C8680` on ivory ≈**3.42:1** (fails regular text). The primary button depends on `:hover` to darken, so a touch-only user sees its less-contrasting resting state. Render critical CTA in dark accent or dark text after designer contrast verification; do not rely on hover. Critical simulator labels and footer descriptions are 11–12px in some locations.
