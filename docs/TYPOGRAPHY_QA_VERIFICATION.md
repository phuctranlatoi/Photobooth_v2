# LE SOUVENIR V2 — P0 typography and motion verification

**Status: CONDITIONAL / NOT signed off.** Static source audit, 7 November 2026. Scope: the four files under `frontend/src/atelier/`, the actual import chain and customer/operator TSX strings. No browser, physical monitor, Windows scaling or hardware capture was exercised. No V1 files were modified. Findings below distinguish authored rules from effective cascade and static evidence from visual verification.

## Source of truth and method

`frontend/src/main.tsx:4-6` imports `styles.css` and initializes the delegated touch effect. `frontend/src/styles.css:1-5` imports Tailwind, then `atelier/theme-tokens.css`, `atelier/atelier-core.css`, `atelier/atelier-customer.css`, `atelier/atelier-operator.css`, in that order. Older parallel stylesheets (`frontend/src/atelier.css`, `frontend/src/operator/atelier-operator.css`, `frontend/src/screens/payment.css`, etc.) exist but are **not imported by this entry point**; do not assume their rules are active. Read all four imported atelier files including the compact multi-selector lines 58-66 of customer CSS, and inspected the customer screens, `Operator.tsx`, `V1Settings.tsx`, operator tabs, `liquidGlassFx.ts` and `CaptureScreen.tsx`. Search for `text-align:justify`, `scaleX(`, letter/word spacing, animations, transitions, keyframes, reduced-motion blocks and pictographic Unicode in source. This is not a computed-style or screenshot test; dynamic catalog names, backend text and uploaded assets cannot be certified by a static string scan.

Validate loaded font via `document.fonts.check` only as a hint; screenshot real glyphs. Check the literal UI stack on normal text and distinguish optional editorial display families.
2. Capture screenshots of every row above at **1920×1200 and 1280×800**, Windows **100%, 125%, 150%** scaling and `prefers-reduced-motion` both normal/reduce. Include long dynamically populated names, payment recovery, printer error, empty states, wrapped buttons and operator table overflow. No screenshots were produced in this audit.
3. Create a non-production text fixture (not a workflow stage) for visual QA: `ă â ê ô ơ ư đ Đ · á à ả ã ạ · ắ ằ ẳ ẵ ặ · ấ ầ ẩ ẫ ậ · ế ề ể ễ ệ · ố ồ ổỗ ộ · ớ ờ ở ỡ ợ · ứ ừ ử ữ ự`; compare upper/lower accents and letter bounding boxes at all font sizes. Keep fixture out of live customer flow.
4. On touch hardware, tap rapidly while spinner, ripple, print pulse, carousel transition and camera preview are active; verify no click is blocked, no duplicate command, no camera frame stall. Inspect Layers/Performance for compositor vs paint, especially pulse shadow. With reduced motion enabled, verify spinner static, ripple absent, print pulse static, smooth scrolling off, and **flash invisible**. Observe actual state progress; never infer a payment or print success from animation.
5. Resolve T1–T4, document any deliberate image-only mirroring exception, repeat source scan **and** visual tests. Do not mark P0 typography or Phase 10/11 complete from this static audit alone.
