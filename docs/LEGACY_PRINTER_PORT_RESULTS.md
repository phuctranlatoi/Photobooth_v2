# Legacy PrinterJob port

Ported from read-only V1 `src/main/kotlin/com/phuctran/photobooth/desktop/services/DesktopIoServices.kt`, `PrinterService.printImage` and `SystemPrinterService.printImage` lines 22–24 and 36–91. `LegacyPrintable` preserves the single-page callback, imageable origin, integer dimensions, orientation comparison and 90-degree rotation, and stretch. The AWT facade preserves `defaultPage`, full-paper imageable-area request, and the sole `Copies` request attribute. Driver clamping, queueing and physical output are not established by these calls.

Safety differences: authorization defaults to deny before image loading, factory, discovery or job creation; the AWT facade is private. Injection of authorization is a trusted backend boundary, not an IPC boolean. Blank names and invalid copies are rejected; printer selection requires exactly one case-insensitive exact name instead of V1's substring match and silent default fallback. Failure after entering `print` is explicitly uncertain; no automatic retry. `Submitted` only means `print` returned, not verified queue or physical completion. No IPC exposure, discovery endpoint, permission persistence, idempotency, queue monitoring, revenue integration, or cut setting is provided. Backend must not wire permissive authorization to untrusted input; a durable per-job authorization and reconciliation design remains necessary.

The existing simulator is unchanged; pass its already paired strip print file and apply the V1 sheet-count policy in the eventual caller. No RX1HS cut capability is invented. Fake-boundary tests exercise default denial, invalid requests, fake submit, and the V1 callback geometry without printer access. Tests are written but **not run**, to avoid concurrent Gradle execution. Hardware enumeration, driver settings, spooler and physical printing were **NOT TESTED**. A separate authorized hardware test with specified media and paper consumption remains required; SDK/driver redistribution and packaged runtime remain unverified.
