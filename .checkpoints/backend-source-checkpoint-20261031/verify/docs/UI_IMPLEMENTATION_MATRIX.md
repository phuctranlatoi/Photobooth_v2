## Build these reusable patterns now

- **KioskShell:** ivory canvas; wordmark left, restrained persistent “SIMULATOR · no payment / no paper / no revenue” label right. Header 64px, outer padding 24px, gap 20px at 1280×800; 80/40/32 at 1920×1200. One active `<main>`, heading focus on phase change only. Diagnostics separate, not above the session. Do not add a global Home action.
- **ActionBar:** bottom grid row, never absolute over images; primary 64px high, secondary 56px, minimum target 48×48 and gaps 12px. At 1280×800 reserve 88px including spacing; pair primary and outlined Back horizontally where space permits. Three-dot menu is a 56px outlined square, never a full-width black CTA. Disable command controls during the existing shared request latch and reconciliation error. Pending text keeps button width stable. Do not replace backend idempotency with debounce.
- **EditorialPanel:** surface #FFFCF7, 1px #D7CEC1 boundary, 12px radius, 24px padding; no glass/gradients. Selected card: 3px #715A36 outline, #EAD8D3 accent tab, explicit check/“Selected”; never color alone. Primary #191817/white; secondary ivory/ink with visible outline. Champagne #B69A70 is decorative only.
- **Typography:** Segoe UI/Arial sans, body 20/30, compact 18/27, buttons 20/26 semibold, page title 40/48, Welcome 56/62. Editorial serif optional on Welcome only with installed glyph coverage; no font files. Numeric countdown `clamp(112px,17vh,240px)`, tabular lining digits, no letter spacing. Wrap Vietnamese/Korean without fixed-height clipping; instructions are not all caps.
- **ContentSplit:** remaining-height `minmax(0,1fr)` grid; preview and choices independently bounded. Use `min-height:0` on grid children; scroll choice region, not the action bar. Quantity choices wrap in a bounded grid with 56px cells; render the full backend list, not a locally chosen ceiling. Selection tiles explicitly use column layout, no fixed tall filler card.
- **PhotoStage:** charcoal #101010 well reserves height before image arrival. Image `object-fit:contain`, natural aspect, no unconditional mirror/rotation. Numeric rail is a sibling, never a face overlay. Current metadata does not expose orientation controls: do not invent operator flips. Isolate frame presentation from countdown rendering. A missing frame says “Preview temporarily unavailable”; never substitute a completed still and call it live.
- **CommandError:** readable inline error plus “Reconcile status — do not replay”; retain existing identity/lock protections. Never auto-replay stored uncertain mutation or replace identity merely to dismiss an error. Raw paths/internal messages should not be customer copy. Successful recovery requires authoritative current state.
- **Modal:** only SELECTING_PHOTOS/EDITING menu can open cancellation. Continue receives initial focus; trap Tab and Shift+Tab, restore menu focus if still mounted, make background inert, close on phase/session change. Escape means Continue; backdrop does not confirm. Synthetic files are retained: do not use V1 deletion copy in this adapter.

## Timing, accessibility and acceptance gates

`secondsRemaining` is currently capture countdown; the inspected snapshot has no distinct selection/edit inactivity remainder field. Render truthful inactivity explanation, **not an invented ticking selection timer**. Ask architect for explicit remaining/deadline semantics before numeric inactivity UI. Backend timeout auto-fills and reaches DELIVERY with userConfirmed=false; the UI never calls dryrun on local expiry. Polling does not reset inactivity.

Motion: 160ms opacity and at most 8px entrance on non-camera panels; no springs/zoom/ambient motion. Respect prefers-reduced-motion with instantaneous transitions; numeral replacement has no crossfade. No assumed haptics on Windows. Focus ring 3px champagne-ink + 3px ivory offset. Use polite phase announcements, not 500ms polling announcements; countdown must be visually legible without relying on screen-reader chatter or sound.

At 1920×1200 and 1280×800 verify no page horizontal scroll, visible primary action, original image aspect, no text/face overlay. Also inspect CSS viewports 1536×960, 1024×640 and approximately 853×533 (Windows DPI-derived); compact mode outer padding16/header48/footer80 and rail208, scroll non-camera choices instead of shrinking targets. Never transform-scale a desktop canvas. Test Vietnamese/Korean and doubled title length, configured counts above one row, 3-digit countdown, empty catalog/frames/feed, pending frame select, late stale response, modal timeout, uncertain confirm and reload. Measure targets >=48 CSS px; long hold/double tap submits once; Shift+Tab cycles correctly; reduced motion introduces no capture delays.
